# M&M 1.2 — обновление без удаления приложения

Ваш установленный значок M&M остаётся на месте. Заново добавлять приложение на экран Домой не нужно.

1. Откройте **старое установленное M&M** на iPhone.
2. Сначала сохраните резервную копию: **Настройки → Сохранить JSON**. Сохраните загрузку в приложение **«Файлы»**.
3. Включите интернет. Полностью закройте M&M через переключатель приложений и снова откройте **тот же значок**.
4. Дождитесь сообщения **«Доступно обновление»**, закройте формы и нажмите **«Обновить»**. Загрузка может занять некоторое время.
5. Приложение перезапустится. Проверьте операции и цель. В настройках будет написано **M&M · 1.2**.

Если предложение пока не появилось, оставьте приложение открытым с интернетом, затем повторите запуск. В версии 1.1 также есть кнопка **Настройки → Проверить обновление** для следующих выпусков. Старой версии 1.0 этой кнопки не требуется: она проверяет наличие новой версии при регистрации Service Worker во время запуска.

**Не удаляйте приложение, не очищайте историю и данные сайта Safari и не переносите его на другой адрес.** Обновление меняет файлы интерфейса по прежнему адресу https://alexander-ego-dev.github.io/moya-pribyl/. База финансов остаётся прежней: в этом выпуске её структура не меняется. Локальные данные всё равно могут быть удалены пользователем или системой, поэтому резервная копия нужна.

## Что добавлено

На Главной есть блок **«Ваши достижения»**. Нажмите на значки, чтобы увидеть четыре уровня Буси:

| Значок | Условие |
| --- | --- |
| Буся на высоте | Выполнить цель любого месяца на 100% — золотая медаль |
| Супер Буся | Выполнить цель на 120% — голубая эмблема с молнией |
| Гипер Буся | Выполнить цель на 150% — фиолетовая крылатая корона |
| Ультра Буся | Выполнить цель на 200% — многоцветная корона с кристаллом |

Все условия основаны на **чистой прибыли** одного месяца относительно его цели. Прошлые месяцы учитываются автоматически. Будущие операции не дают наград заранее. При 200% открываются все четыре значка; без установленной цели награда не выдаётся. Значки становятся красочными при получении, а до этого показываются приглушёнными с замком.

Значки отражают сохранённые финансовые результаты: после изменения или удаления операций/целей они пересчитываются. Отдельная база наград не нужна: при восстановлении вашей обычной JSON-копии значки появятся снова по её данным.

Тема: **Настройки → Тема → Хэллоуин**. В ней тёмный сливовый фон, оранжевые акценты, тыква и новые значки. Вернуться к светлой, тёмной или системной теме можно в любой момент. Выбор запоминается на устройстве. Название M&M и иконка кошелька на главном экране iPhone сохраняются.

## Проверка обновления разработчиком

Перед сборкой новой версии сохраните `dist` предыдущей версии в `.update-check/previous-dist`. Затем выполните `npm run build` и `node scripts/verify-update.mjs`.

Сценарий запускает обе версии последовательно на одном локальном адресе. В старой версии создаются операция и цель. Затем через настоящую кнопку обновления активируется новый Service Worker. Проверяется точное совпадение всех операций, категорий и целей до и после, а также появление двух заслуженных значков. Каталог `.update-check` локальный и не отправляется в GitHub.
